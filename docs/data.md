# คู่มือข้อมูลเทรน (Training Data) 📚

AI ฉลาดได้แค่ไหน = ข้อมูลที่มันกิน ต่อไปนี้คือแหล่งข้อมูลที่ใช้ได้จริงกับโมเดลเล็กบนโน้ตบุ๊ค

## แหล่งข้อมูลภาษาอังกฤษ 🇬🇧

| แหล่ง | ขนาด | เหมาะกับ | วิธีได้มา |
|---|---|---|---|
| **Project Gutenberg** | ~0.5-2 MB/เล่ม | เริ่มต้นที่สุด ใช้ได้เลย (public domain) | `py data/download_starter_data.py` |
| TinyStories (HuggingFace) | ~200 MB | โมเดลเล็ก เทรนเร็ว ภาษาเรียบง่าย | `datasets` library |
| WikiText-103 (HuggingFace) | ~100 MB | ภาษากึ่งทางการ หลากหลายหัวข้อ | `datasets` library |
| หนังสือ/บทความของคุณเอง | ไม่จำกัด | โมเดลเลียนแบบ "สไตล์คุณ" | วางไฟล์ .txt ลง `data/raw/` |

## แหล่งข้อมูลภาษาไทย 🇹🇭

| แหล่ง | ขนาด | หมายเหตุ |
|---|---|---|
| **Wikipedia ไทย** (API) | ดาวน์โหลดทีละหน้าได้ | สคริปต์ของเราดึงบทความสุ่มมาให้แล้ว, ใช้ได้ (CC BY-SA — ใส่เครดิตใน README) |
| Thai Wikipedia dump | ~1-2 GB (บีบอัด) | ทั้งหมด — ใหญ่ไปสำหรับเริ่ม แต่พอขยายได้ |
| OSCAR / CC-100 (th) | GBs | ข้อมูลเว็บ — ต้องกรองเยอะ |
| ข่าว / บทความ / โน้ตของคุณเอง | ไม่จำกัด | **แนะนำสุด** — เอกลักษณ์เฉพาะตัว |

## หลักการเลือกข้อมูลสำหรับโมเดลเล็ก

1. **เริ่มเล็กก่อน** — 2-5 MB ก็เห็น "AI พูดได้" แล้ว อย่าเริ่มจาก 1 GB (รอเทรนเป็นวัน)
2. **คุณภาพ > ปริมาณ** — ข้อความสะอาด หลากหลาย ดีกว่าข้อความเยอะแต่ซ้ำ/สกปรก
3. **ผสมไทย+อังกฤษ** — โมเดลจะเรียนรู้ทั้งสองภาษา (ตัวอย่างของเราทำแบบนี้)
4. **คิดถึง "สไตล์"** — โมเดลเลียนแบบสิ่งที่มันเห็น อยากได้ AI พูดแบบไหน ให้ข้อมูลแบบนั้น

## ขั้นตอนทั้งหมด (สคริปต์ให้แล้ว)

```bash
# 1. ดาวน์โหลดข้อมูลเริ่มต้น (Gutenberg 3 เล่ม + บทความวิกิไทย 12 หน้า)
py data/download_starter_data.py

# 2. ใส่ข้อมูลของคุณเอง (optional) — วาง .txt ลง data/raw/

# 3. แปลงเป็นไฟล์เทรน (ทำความสะอาด + เทรน tokenizer ใหม่ + แบ่ง train/val)
.venv/Scripts/python model/train/prepare_data.py
```

ผลลัพธ์: `data/train.bin` + `data/val.bin` (พร้อมเทรน) + `data/tokenizer.json` (คำศัพท์ใหม่) + `data/meta.json` (สถิติ)
